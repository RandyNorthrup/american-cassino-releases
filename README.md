## About

American Cassino is a classic card game featuring:
- Full American Cassino rules (capture, build, call, trail)
- Three AI difficulty levels
- Online multiplayer with ranked play
- Themes, achievements, and leaderboards

All installers are built automatically from tagged releases and include
SHA-256 checksums for verification.
